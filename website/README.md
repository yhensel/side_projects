# Yhensel Benitez | Personal Website

Personal CV and portfolio website for Yhensel Benitez, Senior Backend Engineer based in Barcelona.

The site presents professional experience, education, technical skills, and engineering practices in English and Spanish.

## Highlights

- Bilingual interface: English and Spanish, with the selected language remembered locally.
- Responsive single-page CV and portfolio.
- Focus on backend architecture, distributed systems, DDD, event-driven systems, and cloud infrastructure.

## Technology

- HTML, CSS, and vanilla JavaScript
- Bootstrap 5
- AOS, Typed.js, GLightbox, Isotope, Swiper, and PureCounter

All frontend dependencies are included locally under `assets/vendor`, so no package installation or build process is required.

## Run Locally

Open `index.html` in a browser, or serve the directory with a local HTTP server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project Structure

```text
index.html                Main page and CV content
assets/css/main.css       Custom styles
assets/js/main.js         Interface behavior and language switching
assets/js/translations.js English and Spanish translations
assets/img/               Profile and portfolio media
assets/vendor/            Bundled third-party dependencies
```
